# Smart-Parking-System


The Smart Parking System using IoT and Sensors is an intelligent solution designed to reduce urban traffic congestion by guiding drivers to available parking spots in real-time. Using ultrasonic or infrared sensors, microcontrollers like Arduino/Raspberry Pi, and cloud platforms such as Firebase or AWS, the system detects parking occupancy, processes data, and displays live availability through a mobile app built with Flutter or React Native. This results in improved parking efficiency, reduced congestion, and an enhanced user experience.
